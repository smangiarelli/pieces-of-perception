# Pieces of Perception

**Personalized action reports for families of neurodiverse children.**

Pieces of Perception is a web platform that helps parents and caregivers build a comprehensive, shareable guide to their child — covering sensory needs, communication style, emotional patterns, regulation strategies, and more. Reports are generated by AI based on a detailed family-completed questionnaire and are designed to be used alongside doctors, therapists, school teams, and other professionals.

Live site: [piecesofperception.com](https://piecesofperception.com)

## Tech Stack

- **Hosting:** Vercel (auto-deploys from this repo)
- **Database:** Supabase (waitlist signups, user profiles)
- **Payments:** Stripe
- **AI Report Generation:** Anthropic Claude API
- **Frontend:** Plain HTML / CSS / JavaScript — no framework

---

## Legal & Compliance Notes

- Platform is **not a HIPAA-covered entity** but voluntarily follows HIPAA-aligned privacy principles
- Questionnaire collects sensitive data (medication, trauma history, self-injury) — parental authorization and COPPA compliance documented in `privacy.html`
- AI-generated reports are **informational resources only** — not medical advice, clinical assessments, or legal documents. Full disclosure language in `terms.html` Section 2 and `disclaimer.html`
- IEP Goal Recommendations add-on does not constitute legal advice and does not create rights under IDEA
- Anthropic data processing agreement prohibits use of questionnaire data for AI model training
